# Bubble Shooter

A simple and engaging **2D Bubble Shooter game** built with **Godot**. The game focuses on satisfying bubble-shooting mechanics, color matching, and progressively challenging levels.

## About the Game

Aim and shoot bubbles toward the formation at the top of the screen. Match **three or more bubbles of the same color** to clear them and earn points.

Clear the required bubbles to complete a level and progress to the next challenge.

## Features

* Bubble aiming and shooting
* Smooth bubble movement
* Bubble collision and attachment
* 3+ same-color bubble matching
* Automatic matched-bubble removal
* Score system
* Level progression
* Multiple level layouts
* Increasing difficulty
* Win and lose conditions
* Simple and responsive UI

## Gameplay

The basic gameplay loop is:

**Aim → Shoot → Attach → Match → Clear → Score → Progress**

Players need to carefully aim their shots to create larger matching groups and clear the bubble formations efficiently.
